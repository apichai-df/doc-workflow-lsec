# Document Workflow LSEC v4

ระบบอนุมัติเอกสารแบบ **Immutable PDF Revision Workflow**

## หลักการทำงาน
1. เจ้าของอัปโหลด PDF และเป็นผู้ตรวจ/ลงนามขั้นแรก
2. เมื่อกดส่ง ระบบฝั่ง Server ฝังลายเซ็นลง PDF Revision ปัจจุบัน
3. ระบบสร้าง Revision ใหม่ใน Private Supabase Storage
4. ผู้ตรวจคนถัดไปเปิด Revision ล่าสุด จึงเห็นลายเซ็นก่อนหน้าเป็นส่วนหนึ่งของ PDF จริง
5. เมื่อจบ Workflow ระบบอัปโหลด PDF ฉบับสุดท้ายไป SharePoint

## UX
- เอกสารของฉัน: เจ้าของเห็นเอกสารตลอดและเห็น Progress ทุกขั้น
- งานที่รอตรวจ: แสดงเฉพาะงานที่ active และมอบหมายถึงผู้ใช้
- ประวัติการตรวจ: งานที่ส่งต่อหรือส่งกลับแล้ว
- เอกสารหายจาก Inbox ทันทีหลังสร้าง Revision และส่งต่อสำเร็จ
